# 逻辑模块划分

Redis 代码库采用模块化设计，各模块职责清晰、相互协作。本章详细描述各核心模块的功能与相互关系。

## 模块总览

```
src/
├── server.c          # 服务器核心 - 全局状态、命令调度
├── db.c              # 数据库操作 - KV 存储、键空间管理
├── networking.c      # 网络处理 - 连接管理、协议解析
├── ae.c              # 事件循环 - 事件驱动框架
├── rdb.c             # RDB 持久化
├── aof.c             # AOF 持久化
├── replication.c     # 数据复制
├── cluster.c         # 集群管理
├── object.c          # 对象系统
├── dict.c            # 哈希表
├── sds.c             # 动态字符串
├── quicklist.c       # 压缩列表
├── listpack.c        # 紧凑列表
└── rax.c             # 基数树
```

---

## 1. 服务器核心模块 (server.c)

### 职责
- 维护全局状态（`struct redisServer server`）
- 命令查找与调度
- 定时任务执行（Cron）
- 信号处理
- 日志系统

### 核心数据结构

```c
struct redisServer {
    // 事件循环
    aeEventLoop *el;

    // 客户端管理
    list *clients;              // 所有客户端
    rax *clients_index;         // 按 ID 索引的客户端

    // 数据库
    redisDb *db;                // 数据库数组
    int dbnum;                  // 数据库数量

    // 持久化状态
    int rdb_save_time_last;     // 上次 RDB 保存时间
    int aof_state;              // AOF 状态

    // 复制状态
    int masterhost;             // 主节点地址
    int masterport;             // 主节点端口
    list *slaves;               // 从节点列表

    // 全局统计
    unsigned long long stat_numcommands;
    unsigned long long stat_net_input_bytes;
    unsigned long long stat_net_output_bytes;

    // 配置
    int port;
    char *bindaddr[CONFIG_BINDADDR_MAX];
    char *logfile;
    int verbosity;

    // ... 更多字段
};
```

### 关键函数

| 函数 | 功能 |
|------|------|
| `main()` | 程序入口，初始化并启动事件循环 |
| `initServer()` | 初始化服务器状态 |
| `serverCron()` | 定时任务（每秒执行 10 次） |
| `processCommand()` | 处理客户端命令 |
| `call()` | 执行命令并处理后续操作 |

### 命令处理流程

```
客户端请求 → readQueryFromClient() → processInputBuffer()
           → processCommand() → call() → 命令执行
```

## 2. 数据库模块 (db.c)

### 职责
- 键值对存储操作
- 键空间（keyspace）管理
- 过期键处理
- 键大小统计

### 核心数据结构

```c
typedef struct redisDb {
    kvstore *keys;              // 键空间哈希表
    kvstore *expires;           // 过期时间哈希表
    dict *blocking_keys;        // 阻塞的键
    dict *ready_keys;           // 就绪的键
    dict *watched_keys;         // 被 WATCH 的键
    int id;                     // 数据库 ID
} redisDb;
```

### 关键操作

| 操作 | 函数 | 描述 |
|------|------|------|
| 查找 | `lookupKeyRead()` / `lookupKeyWrite()` | 获取键（可能触发过期删除） |
| 添加 | `dbAdd()` | 添加新键值对 |
| 删除 | `dbDelete()` | 删除键值对 |
| 随机 | `dbRandomKey()` | 返回随机键 |

### 过期键删除策略

1. **惰性删除** - 访问键时检查是否过期
2. **定期删除** - `activeExpireCycle()` 定期扫描

```c
// expireIfNeeded() 返回值
typedef enum {
    KEY_VALID,    // 键有效
    KEY_EXPIRED,  // 键已过期但未删除
    KEY_DELETED   // 键已被删除
} keyStatus;
```

## 3. 网络模块 (networking.c)

### 职责
- 客户端连接管理
- RESP 协议解析
- 输入/输出缓冲区管理
- 命令参数解析

### RESP 协议格式

```
简单字符串：+OK\r\n
错误：-Error message\r\n
整数：:100\r\n
批量字符串：$5\r\nhello\r\n
数组：*2\r\n$3\r\nGET\r\n$3\r\nkey\r\n
```

### 客户端数据结构

```c
typedef struct client {
    connection *conn;           // 连接

    // 查询缓冲区
    sds querybuf;               // 输入缓冲区
    int qb_pos;                 // 已读取位置

    // 命令参数
    robj **argv;                // 命令参数数组
    int argc;                   // 参数数量

    // 响应缓冲区
    list *reply;                // 响应列表
    int bufpos;                 // 固定缓冲区使用位置
    char buf[PROTO_REPLY_CHUNK_BYTES];

    // 状态标志
    int flags;                  // 客户端标志
    int authenticated;          // 是否已认证

    // 复制相关
    int replstate;              // 复制状态
    long long reploff;          // 复制偏移量

    // ... 更多字段
} client;
```

### 关键函数

| 函数 | 功能 |
|------|------|
| `createClient()` | 创建新客户端 |
| `freeClient()` | 释放客户端 |
| `readQueryFromClient()` | 读取客户端请求 |
| `addReply()` | 添加响应 |
| `processInputBuffer()` | 解析输入缓冲区 |

## 4. 事件循环模块 (ae.c)

### 职责
- 文件事件管理（可读/可写）
- 时间事件管理
- 多路复用后端抽象

### 支持的后端

| 后端 | 文件 | 适用平台 |
|------|------|----------|
| select | `ae_select.c` | 所有平台 |
| epoll | `ae_epoll.c` | Linux |
| kqueue | `ae_kqueue.c` | BSD/macOS |
| evport | `ae_evport.c` | Solaris |

### 事件类型

```c
#define AE_READABLE 1     // 文件可读
#define AE_WRITABLE 2     // 文件可写
#define AE_BARRIER 4      // 屏障模式
#define AE_TIME_EVENTS 1  // 时间事件
```

### 核心 API

```c
aeEventLoop *aeCreateEventLoop(int setsize);
int aeCreateFileEvent(aeEventLoop *el, int fd, int mask,
                      aeFileProc *proc, void *clientData);
long long aeCreateTimeEvent(aeEventLoop *el, long long ms,
                            aeTimeProc *proc, void *clientData,
                            aeEventFinalizerProc *finalizer);
int aeProcessEvents(aeEventLoop *el, int flags);
void aeMain(aeEventLoop *el);
```

## 5. 对象系统 (object.c)

### 职责
- 统一对象封装
- 引用计数管理
- 内存优化（共享对象、嵌入字符串）

### 对象结构

```c
typedef struct redisObject {
    unsigned type:4;      // 对象类型
    unsigned encoding:4;  // 编码方式
    unsigned lru:24;      // LRU/LFU 信息
    int refcount;         // 引用计数
    void *ptr;            // 数据指针
} robj;
```

### 对象类型与编码

| 类型 | 编码 | 描述 |
|------|------|------|
| OBJ_STRING | OBJ_ENCODING_RAW | 原始 SDS 字符串 |
| OBJ_STRING | OBJ_ENCODING_EMBSTR | 嵌入 SDS 字符串（≤44 字节） |
| OBJ_STRING | OBJ_ENCODING_INT | 整数 |
| OBJ_LIST | OBJ_ENCODING_QUICKLIST | 压缩列表链表 |
| OBJ_SET | OBJ_ENCODING_INTSET | 整数集合 |
| OBJ_SET | OBJ_ENCODING_LISTPACK | 紧凑列表 |
| OBJ_HASH | OBJ_ENCODING_LISTPACK | 紧凑列表 |
| OBJ_HASH | OBJ_ENCODING_HT | 哈希表 |
| OBJ_ZSET | OBJ_ENCODING_LISTPACK | 紧凑列表 |
| OBJ_ZSET | OBJ_ENCODING_SKIPLIST | 跳表 |

## 6. 集群模块 (cluster.c)

### 职责
- 分布式哈希表实现
- 槽位（slot）管理
- 节点发现与通信
- 故障转移

### 槽位分配

- 总共 **16384** 个槽位
- 键的槽位计算：`CRC16(key) & 0x3FFF`

```c
// 槽位映射
clusterNode *getNodeBySlot(int slot);
int clusterNodeCoversSlot(clusterNode *n, int slot);
```

### 重定向机制

| 错误 | 描述 |
|------|------|
| `-MOVED` | 槽位已迁移，客户端需更新路由表 |
| `-ASK` | 槽位正在迁移，临时重定向 |
| `-CLUSTERDOWN` | 集群不可用 |
