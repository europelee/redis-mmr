# 核心数据结构

Redis 的高效性能源于其精心设计的数据结构。本章详细介绍 Redis 使用的核心数据结构。

## 数据结构总览

```
基础数据结构：
├── sds.h/c      - 动态字符串 (Simple Dynamic String)
├── dict.h/c     - 哈希表 (Hash Table)
├── adlist.h/c   - 双向链表 (Doubly Linked List)
├── rax.h/c      - 基数树 (Radix Tree)
├── quicklist.h/c - 压缩列表链表
├── listpack.h/c - 紧凑列表 (Listpack)
└── intset.h/c   - 整数集合 (Integer Set)

对象系统：
└── object.c     - Redis 对象封装 (robj)
```

## 1. SDS - 动态字符串 (sds.h/c)

### 设计目标
- O(1) 复杂度的字符串长度获取
- 安全的二进制安全字符串
- 减少内存分配次数
- 支持修改操作

### 数据结构

SDS 提供 5 种头部格式，根据字符串长度选择最合适的编码：

```c
/* SDS Type 5: 1 字节头，5 位存储长度 */
struct __attribute__ ((__packed__)) sdshdr5 {
    unsigned char flags; /* 3 位类型 + 5 位长度 */
    char buf[];
};

/* SDS Type 8: 3 字节头 */
struct __attribute__ ((__packed__)) sdshdr8 {
    uint8_t len;           /* 已使用长度 */
    uint8_t alloc;         /* 总分配长度 (不含头和 null 终止符) */
    unsigned char flags;   /* 3 位类型，5 位未使用 */
    char buf[];
};

/* SDS Type 16: 6 字节头 */
struct __attribute__ ((__packed__)) sdshdr16 {
    uint16_t len;
    uint16_t alloc;
    unsigned char flags;
    char buf[];
};

/* SDS Type 32: 10 字节头 */
struct __attribute__ ((__packed__)) sdshdr32 {
    uint32_t len;
    uint32_t alloc;
    unsigned char flags;
    char buf[];
};

/* SDS Type 64: 18 字节头 */
struct __attribute__ ((__packed__)) sdshdr64 {
    uint64_t len;
    uint64_t alloc;
    unsigned char flags;
    char buf[];
};
```

### 内存布局

```
sdshdr8 示例 (字符串 "hello", 长度 5):
  +------+------+------+--------+---+
  | len  |alloc |flags | "hello"| \0|
  |  5   |  10  | type8|        |   |
  +------+------+------+--------+---+
  |<- 3 字节头 ->|<- 5 字节 ->|<-1|

sds 指针指向 buf[0]，通过 s[-1] 访问 flags
```

### 核心 API

```c
sds sdsnewlen(const void *init, size_t initlen);  // 创建字符串
sds sdsempty(void);                                // 创建空字符串
sds sdscatlen(sds s, const void *t, size_t len);  // 追加字符串
sds sdscpylen(sds s, const char *t, size_t len);  // 复制字符串
size_t sdslen(const sds s);                        // 获取长度
void sdsfree(sds s);                               // 释放
```

### 预分配策略

- 修改后长度 < 1MB：分配双倍空间
- 修改后长度 >= 1MB：最多分配 1MB 额外空间
- 最大预分配：`SDS_MAX_PREALLOC (1MB)`

## 2. Dict - 哈希表 (dict.h/c)

### 设计目标
- 平均 O(1) 的查找/插入/删除
- 渐进式 rehash，避免阻塞
- 支持多种键值类型

### 数据结构

```c
/* 哈希表类型定义 */
typedef struct dictType {
    uint64_t (*hashFunction)(const void *key);
    void *(*keyDup)(dict *d, const void *key);
    void *(*valDup)(dict *d, const void *obj);
    int (*keyCompare)(dictCmpCache *cache, const void *key1, const void *key2);
    void (*keyDestructor)(dict *d, void *key);
    void (*valDestructor)(dict *d, void *obj);
    /* 可选回调 */
    void (*rehashingStarted)(dict *d);
    void (*rehashingCompleted)(dict *d);
    /* ... */
} dictType;

/* 哈希表结构 */
struct dict {
    dictType *type;              // 类型定义

    dictEntry **ht_table[2];     // 两个哈希表 (用于 rehash)
    unsigned long ht_used[2];    // 已使用槽位数量

    long rehashidx;              // rehash 进度 (-1 表示未进行)
    unsigned pauserehash;        // 暂停 rehash 标志

    signed char ht_size_exp[2];  // 表大小的指数 (size = 1<<exp)
    signed pauseAutoResize: 15;  // 暂停自动调整大小
    unsigned useStoredKeyApi: 1; // 使用存储键 API
    void *metadata[];            // 元数据
};

/* 哈希表条目 */
typedef struct dictEntry {
    void *key;
    union {
        void *val;
        uint64_t u64;
        int64_t i64;
        double d;
        dictEntry *next;
    } v;
} dictEntry;
```

### 内存布局

```
dict 结构:
  +------------+
  | dictType * |  type
  +------------+
  | ht_table[0]|---> [dictEntry*][dictEntry*]...  (桶数组)
  | ht_table[1]|---> [dictEntry*][dictEntry*]...  (rehash 用)
  +------------+

dictEntry 链式结构:
  ht_table[i] --> dictEntry --> dictEntry --> NULL
                  (key, val)    (key, val)
```

### 渐进式 Rehash

Redis 使用两个哈希表实现渐进式 rehash：

1. **初始状态**: ht_table[0] 使用，ht_table[1] 为空
2. **开始 rehash**: 设置 rehashidx = 0
3. **渐进迁移**: 每次操作迁移 ht_table[0] 的部分桶到 ht_table[1]
4. **完成**: ht_table[0] 清空，释放，ht_table[1] 成为 ht_table[0]

```c
// rehash 步骤
int dictRehash(dict *d, int n) {
    // n 是要迁移的桶数量
    // 在每次 serverCron() 时调用
}

// 查找时检查两个表
dictEntry *dictFind(dict *d, const void *key) {
    if (dictIsRehashing(d)) {
        // 在 ht_table[1] 查找
        // 如果没找到，在 ht_table[0] 查找
    } else {
        // 只在 ht_table[0] 查找
    }
}
```

### 负载因子与调整

```c
// 负载因子计算
float load_factor = dictSize(d) / DICTHT_SIZE(d->ht_size_exp[0]);

// 扩容条件：负载因子 > 1
// 缩容条件：负载因子 < 0.1
```

### 核心 API

```c

int dictAdd(dict *d, void *key, void *val);
dictEntry *dictFind(dict *d, const void *key);
int dictDelete(dict *d, const void *key);

```

## 3. Quicklist - 压缩列表链表 (quicklist.h/c)

### 设计目标
- 结合链表和压缩列表的优点
- 内存紧凑
- 快速的两端操作

### 数据结构

```
quicklist 结构:
  +--------+     +--------+     +--------+     +--------+
  |  head  |<--->| node 1 |<--->| node 2 |<--->|  tail  |
  +--------+     +--------+     +--------+     +--------+
                   |              |
                   v              v
               +---------+    +---------+
               | ziplist |    | ziplist |
               | entry 1 |    | entry 1 |
               | entry 2 |    | entry 2 |
               |  ...    |    |  ...    |
               +---------+    +---------+
```

### 节点结构

```c
typedef struct quicklistNode {
    struct quicklistNode *prev;
    struct quicklistNode *next;
    unsigned char *entry;      // 压缩列表数据
    size_t sz;                 // 节点大小
    unsigned int count : 24;   // 条目数量
    unsigned int encoding : 2; // RAW(0) 或 LZF(1)
    unsigned int container : 2;// PLAIN(0) 或 PACKED(1)
    unsigned int recompress : 1;
    unsigned int attempted_compress : 1;
} quicklistNode;
```

### 核心 API

```c
quicklist *quicklistCreate(void);
quicklistNode *quicklistCreateNode(const void *value, size_t sz);
void quicklistPushHead(quicklist *quicklist, void *value, size_t sz);
void quicklistPushTail(quicklist *quicklist, void *value, size_t sz);
quicklistEntry *quicklistNext(quicklistIter *iter, quicklistEntry *node);
void quicklistRelease(quicklist *quicklist);
```

## 4. Listpack - 紧凑列表 (listpack.h/c)

### 设计目标
- 连续内存存储
- 紧凑编码
- 支持快速随机访问

### 内存布局

```
+----------+---------+----+--------+---------+----------+
| total_sz | num_ele | e1 | len_1  | entry_1 | 0xff     |
+----------+---------+----+--------+---------+----------+
  ^          ^                      ^           ^
  |          |                      |           |
total bytes  entry count         entry i     end marker
```

### 编码格式

```
整数编码 (小整数):
  | 0xxxxxxx |  (7 位整数，范围 0-127)
  | 110xxxxx |  (5 位整数，范围 -16 到 -1)
  | 1110xxxx |xxxxxxxx|  (12 位整数)

字符串编码:
  | len | data... |
```

### 核心 API

```c
unsigned char *lpNew(unsigned int capacity);
unsigned char *lpPush(unsigned char *lp, unsigned char *data, uint64_t sz);
unsigned char *lpFind(unsigned char *lp, unsigned char *p,
                      unsigned char *s, uint64_t slen, unsigned int skip);
unsigned char *lpNext(unsigned char *lp, unsigned char *p);
void lpFree(unsigned char *lp);
```

## 5. Rax - 基数树 (rax.h/c)

### 设计目标
- 内存高效的字符串索引结构
- 支持前缀匹配
- O(k) 查找复杂度 (k 为键长度)

### 数据结构

```c
typedef struct raxNode {
    uint32_t iskey:1;     // 是否为键的终点
    uint32_t isnull:1;    // 是否为空值
    uint32_t kompress:1;  // 是否压缩
    uint32_t size:29;     // 子节点数量
    // 后面跟随数据:
    // 1. edges[] - 边数组 (字符 + 子节点指针)
    // 2. data    - 键值 (如果是键)
} raxNode;

typedef struct rax {
    raxNode *head;        // 根节点
    uint64_t numele;      // 元素数量
    uint64_t bytes;       // 占用字节数
    raxNode **stack;      // 迭代器栈
} rax;
```

### 核心 API

```c
rax *raxNew(void);
int raxInsert(rax *rax, unsigned char *s, size_t len, void *data, void **old);
void *raxFind(rax *rax, unsigned char *s, size_t len);
int raxRemove(rax *rax, unsigned char *s, size_t len, void **old);
raxIterator *raxIteratorNew(void);
int raxSeek(raxIterator *it, const char *op, unsigned char *ele, size_t len);
int raxNext(raxIterator *it);
int raxPrev(raxIterator *it);
void raxFree(rax *rax);
```

## 6. 对象系统 (object.c)

### Redis 对象结构

```c
typedef struct redisObject {
    unsigned type:4;        // 类型 (4 位)
    unsigned encoding:4;    // 编码 (4 位)
    unsigned lru:24;        // LRU 时间/LFU 计数器 (24 位)
    int refcount;           // 引用计数
    void *ptr;              // 数据指针
} robj;
```

### 对象类型

```c
#define OBJ_STRING 0     // 字符串
#define OBJ_LIST   1     // 列表
#define OBJ_SET    2     // 集合
#define OBJ_ZSET   3     // 有序集合
#define OBJ_HASH   4     // 哈希
#define OBJ_MODULE 5     // 模块
#define OBJ_STREAM 6     // 流
```

### 编码方式

```c
#define OBJ_ENCODING_RAW       0     // 原始字符串
#define OBJ_ENCODING_INT       1     // 整数
#define OBJ_ENCODING_EMBSTR    8     // 嵌入字符串
#define OBJ_ENCODING_HT        2     // 哈希表
#define OBJ_ENCODING_ZIPLIST   9     // 压缩列表 (旧)
#define OBJ_ENCODING_LISTPACK  10    // 紧凑列表
#define OBJ_ENCODING_INTSET    3     // 整数集合
#define OBJ_ENCODING_SKIPLIST  4     // 跳表
#define OBJ_ENCODING_QUICKLIST 12    // 压缩列表链表
```

### 字符串对象优化

```
EMBSTR 编码 (嵌入字符串，≤44 字节):
+----------+------------------+
|  robj    |  sdshdr + data   |
| (16 字节) |  (最多 32 字节)   |
+----------+------------------+
一次分配，内存连续，提高缓存命中率
```

### 引用计数与共享对象

```c
// 创建共享对象
robj *makeObjectShared(robj *o) {
    o->refcount = OBJ_SHARED_REFCOUNT;
    return o;
}

// 增减引用计数
void incrRefCount(robj *o);
void decrRefCount(robj *o);
```

## 数据结构选择策略

### 列表 (List)
- 元素少：listpack
- 元素多：quicklist

### 集合 (Set)
- 元素少且为整数：intset
- 元素少：listpack
- 元素多：dict (哈希表)

### 哈希 (Hash)
- 元素少：listpack
- 元素多：dict (哈希表)

### 有序集合 (ZSet)
- 元素少：listpack
- 元素多：skiplist + dict
