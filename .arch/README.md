## 核心组件简述

### 1. 逻辑模块
- **服务器核心** - 全局状态、命令调度、定时任务
- **数据库模块** - KV 存储、键空间管理、过期策略
- **网络模块** - 连接管理、RESP 协议、缓冲区
- **持久化模块** - RDB 快照、AOF 追加
- **复制模块** - 主从同步、复制积压、部分重同步
- **集群模块** - 分布式哈希表、节点通信
- **事件系统** - 文件事件、时间事件

### 2. 数据结构
- **dict** - 哈希表（渐进式 rehash）
- **sds** - 动态字符串（5 种编码）
- **quicklist** - 压缩列表链表
- **rax** - 基数树
- **ziplist/listpack** - 紧凑列表

### 3. 数据同步
- 全量同步（BGSAVE + RDB 传输）
- 增量同步（复制积压缓冲区）
- PSYNC 部分重同步
- 无磁盘复制（diskless replication）
- RDB Channel 机制

### 4. 持久化
- **RDB** - 定时快照、二进制紧凑格式
- **AOF** - 命令日志、可配置 fsync 策略
- **混合持久化** - RDB+AOF 结合
